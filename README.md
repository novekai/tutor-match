# Tutor Match

Prototype de matching intelligent entre élèves et tuteurs, avec réservation automatique d'un créneau.

- **Front** : React + Vite + TypeScript + Tailwind (`frontend/`)
- **API** : Laravel, REST/JSON (`backend/`)
- **Base** : PostgreSQL

Documentation : [architecture](docs/ARCHITECTURE.md) · [plan de développement](docs/PLAN.md)
